## Running inside the VM

Builds/uses the image-provided Charlotte binaries, starts local demo services,
and opens the guided Chromium presentation. The director runs unattended in
the VM; the host HTTP listener responds on port 8080.

    CHARLOTTE_DEMO_STATE=/tmp/charlotte-demo demo/run.sh --auto &
    # ready when http://127.0.0.1:8080 responds 200 and Chromium shows the demo

The demo is isolated to `*.charlotte.test` and loopback services. Pebble is a
local ACME test CA; certificate requests are generated by visiting the demo
site over HTTP. Set `--auto` for unattended playback; omit it when running
interactively to advance each scene with Enter or Space/Right Arrow.
